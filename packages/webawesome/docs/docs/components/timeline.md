Each entry is a [`<wa-timeline-item>`](/docs/components/timeline-item). If you need to track a user's own progress through a linear, gated process instead of a passive record, use [`<wa-stepper>`](/docs/components/stepper) instead.

## Examples

### Providing Content

An item's default slot isn't limited to a title and a line of text — it's regular content, so it can hold anything, like an avatar and a comment in a pull request's activity log. This is the main way a timeline earns its keep over [`<wa-stepper>`](/docs/components/stepper): a step is a compact label built for a rail, an item is a full record built to hold whatever the event actually was.

```html {.example}
<wa-timeline>
  <wa-timeline-item>
    <time slot="opposite" datetime="2026-09-14T09:12:00">9:12 AM</time>
    <div class="timeline-comment">
      <wa-avatar initials="JK" label="Jamie Kim"></wa-avatar>
      <div>
        <strong>Jamie Kim</strong> opened the pull request
        <p>Adds the timeline component and its docs.</p>
      </div>
    </div>
  </wa-timeline-item>
  <wa-timeline-item variant="warning">
    <time slot="opposite" datetime="2026-09-14T11:03:00">11:03 AM</time>
    <div class="timeline-comment">
      <wa-avatar initials="RP" label="Riley Park"></wa-avatar>
      <div>
        <strong>Riley Park</strong> requested changes
        <p>Can we add a test for an empty <code>opposite</code> slot before merging this?</p>
      </div>
    </div>
  </wa-timeline-item>
  <wa-timeline-item current variant="success">
    <time slot="opposite" datetime="2026-09-15T08:47:00">Yesterday</time>
    <div class="timeline-comment">
      <wa-avatar initials="JK" label="Jamie Kim"></wa-avatar>
      <div><strong>Jamie Kim</strong> merged the pull request</div>
    </div>
  </wa-timeline-item>
</wa-timeline>
```

### Opposite Content

Add content to an item's `opposite` slot to show it apart from the main content — commonly a date or timestamp, wrapped in a `<time>` element so the value stays machine-readable. Here it's the year in a company's own history.

```html {.example}
<wa-timeline>
  <wa-timeline-item>
    <time slot="opposite" datetime="2019">2019</time>
    <strong>Founded in a garage</strong>
    <p>Two co-founders, one laptop, and a very optimistic roadmap.</p>
  </wa-timeline-item>
  <wa-timeline-item>
    <time slot="opposite" datetime="2021">2021</time>
    <strong>Raised our Series A</strong>
    <p>Grew the team from 4 to 30 and shipped our first enterprise plan.</p>
  </wa-timeline-item>
  <wa-timeline-item current>
    <time slot="opposite" datetime="2026">2026</time>
    <strong>Opened our third office</strong>
    <p>Still optimistic. Roadmap is now merely ambitious.</p>
  </wa-timeline-item>
</wa-timeline>
```

### Variant

Set the `variant` attribute on an item to color its marker and the connector after it with a semantic color, the same options as [`<wa-badge>`](/docs/components/badge). Pair it with a clear label — the color is cosmetic and never changes what the marker shows.

```html {.example}
<wa-timeline>
  <wa-timeline-item variant="success">
    <strong>Build passed</strong>
    <p>All checks succeeded.</p>
  </wa-timeline-item>
  <wa-timeline-item variant="warning">
    <strong>Deploy delayed</strong>
    <p>Waiting on a manual approval.</p>
  </wa-timeline-item>
  <wa-timeline-item variant="danger">
    <strong>Rollback triggered</strong>
    <p>Error rate exceeded the threshold.</p>
  </wa-timeline-item>
</wa-timeline>
```

### Custom Marker

Use the `marker` slot to replace an item's default dot with custom content, such as a [`<wa-icon>`](/docs/components/icon) — handy for a security or audit log, where the icon itself carries most of the meaning.

```html {.example}
<wa-timeline>
  <wa-timeline-item variant="success">
    <wa-icon slot="marker" name="arrow-right-to-bracket"></wa-icon>
    <time slot="opposite" datetime="2026-09-15T08:02:00">8:02 AM</time>
    <strong>Signed in</strong>
    <p>New device — MacBook Pro, San Francisco</p>
  </wa-timeline-item>
  <wa-timeline-item variant="warning">
    <wa-icon slot="marker" name="key"></wa-icon>
    <time slot="opposite" datetime="2026-09-15T08:04:00">8:04 AM</time>
    <strong>Password changed</strong>
  </wa-timeline-item>
  <wa-timeline-item current variant="brand">
    <wa-icon slot="marker" name="square-check"></wa-icon>
    <time slot="opposite" datetime="2026-09-15T08:05:00">8:05 AM</time>
    <strong>Two-factor authentication enabled</strong>
  </wa-timeline-item>
</wa-timeline>
```

### Size

A timeline is sized relative to the current font size, like a badge. Set `font-size` on the timeline (or an ancestor element) to change it; markers, connectors, and text scale together.

```html {.example}

  <wa-timeline class="size-timeline" style="font-size: var(--wa-font-size-xs);">
    <wa-timeline-item current>Order placed</wa-timeline-item>
    <wa-timeline-item>Shipped</wa-timeline-item>
```

### Alignment

Set the `alignment` attribute to `end` to move every item's marker to the end side of the rail instead of the start. Set it to `alternate` to flip each item to the opposite side of its sibling, useful for a wide, centered timeline — like a product roadmap down the middle of a page.

```html {.example}
<wa-timeline alignment="alternate">
  <wa-timeline-item variant="success">
    <wa-badge slot="opposite" appearance="outlined" variant="success" pill>Shipped</wa-badge>
    <strong>Bulk actions in the data grid</strong>
    <p>Select rows across pages and act on them all at once.</p>
  </wa-timeline-item>
  <wa-timeline-item current variant="brand">
    <wa-badge slot="opposite" appearance="outlined" variant="brand" pill>In progress</wa-badge>
    <strong>Real-time collaboration</strong>
    <p>See where teammates are editing as they type.</p>
  </wa-timeline-item>
  <wa-timeline-item>
    <wa-badge slot="opposite" appearance="outlined" pill>Planned</wa-badge>
    <strong>Offline mode</strong>
    <p>Keep working on a flight; sync once you land.</p>
  </wa-timeline-item>
</wa-timeline>
```

### Animate on Scroll

Add the `animate-on-scroll` attribute to draw each connector as it scrolls into view, instead of showing every line fully drawn up front. It's pure CSS — a [scroll-driven animation](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_scroll-driven_animations) tied to each connector's own position in whatever scrolls it, so it works the same whether that's the page or a scrollable container like the one below. Only applies when `orientation` is `vertical`. Scroll the box to see it draw.

```html {.example}
<div style="block-size: 16em; overflow-y: auto; padding-inline: 1em;">
  <div style="block-size: 14em;"></div>
  <wa-timeline animate-on-scroll style="--gap: var(--wa-space-3xl);">
    <wa-timeline-item variant="success">Order placed</wa-timeline-item>
    <wa-timeline-item variant="success">Order shipped</wa-timeline-item>
    <wa-timeline-item current>Out for delivery</wa-timeline-item>
    <wa-timeline-item>Delivered</wa-timeline-item>
  </wa-timeline>
  <div style="block-size: 8em;"></div>
</div>
```

:::info
Older browsers, and anyone with `prefers-reduced-motion` set, just see every connector fully drawn — the same as without the attribute.
:::

### Updating Live

A timeline is just markup — there's no API for adding an entry, the same way there's nothing to call to add a row to a table. Append a new `<wa-timeline-item>` and move `current` yourself, e.g. once a live status actually changes. Here, opening a support ticket adds the first entry, and each reply appends another.

```html {.example}
<div class="timeline-live-demo">
  <wa-timeline id="timeline-live">
    <wa-timeline-item current variant="warning">
      <time slot="opposite">9:02 AM</time>
      <strong>Ticket opened</strong>
      <p>"The export button spins forever on large reports."</p>
    </wa-timeline-item>
  </wa-timeline>

  <wa-divider></wa-divider>

  <wa-button id="timeline-live-advance" appearance="filled">Add Reply</wa-button>
</div>

<script>
  const timelineLive = document.getElementById('timeline-live');
  const timelineLiveButton = document.getElementById('timeline-live-advance');
  const timelineLiveSteps = [
    {
      time: '9:47 AM',
      variant: 'brand',
      label: 'Support replied',
      body: 'Can you share which report and roughly how many rows?',
    },
    {
      time: '10:15 AM',
      variant: 'brand',
      label: 'Fix deployed',
      body: 'Exports over 10k rows now stream instead of loading in memory.',
    },
    { time: '10:20 AM', variant: 'success', label: 'Ticket resolved', body: '' },
  ];

  timelineLiveButton.addEventListener('click', () => {
    const next = timelineLiveSteps.shift();
    if (!next) return;

    timelineLive.querySelector('wa-timeline-item[current]')?.removeAttribute('current');

    const item = document.createElement('wa-timeline-item');
    item.current = true;
    item.variant = next.variant;
    item.innerHTML = `<time slot="opposite">${next.time}</time><strong>${next.label}</strong>${next.body ? `<p>${next.body}</p>` : ''}`;
    timelineLive.append(item);

    if (timelineLiveSteps.length === 0) timelineLiveButton.disabled = true;
  });
</script>
```

### Customizing

The `marker` part belongs to `<wa-timeline-item>`, so the selector targets the items, not the timeline; see the [Timeline Item page](/docs/components/timeline-item#css-parts) for every part an item exposes.

## Accessibility Considerations

#### Structure

The timeline renders an ordered list, and each `<wa-timeline-item>` carries `role="listitem"`.

#### Current Entry

The `current` attribute is purely visual — unlike `<wa-stepper>`'s active step, nothing about a timeline entry is announced as "current" to assistive technology, since a timeline doesn't track a single position the way a stepper does. If which entry is current matters to the reader, say so in the entry's visible content (e.g. "Out for delivery" instead of relying on the marker's highlight alone).

#### Focus

A timeline item is never focusable on its own — it's a record, not a control, so there's nothing equivalent to `<wa-stepper>`'s `clickable` steps. If an item needs to link somewhere or trigger an action, put a real `<a>` or `<wa-button>` in its content; the timeline itself never intercepts clicks or adds keyboard handling.

#### Color and Meaning

The `variant` attribute is cosmetic. It changes color, which doesn't carry meaning on its own, so state the reason in the item's visible content rather than relying on color alone.

#### Custom Markers

When the `marker` slot holds an icon that's the only indicator of an item's meaning (e.g. a checkmark for "completed" with no other label), give it an accessible name with [`<wa-icon label="...">`](/docs/components/icon). A marker that only repeats what the item's own content already says can stay decorative.
